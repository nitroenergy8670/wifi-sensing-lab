# Wi-Fi Sensing Lab

고정 2.4 GHz 공유기 1대와 ESP32-S3 수신기 6대(공동 앵커 보드 전환)로, 장치를 지니지 않은 사람의 위치·자세·재실을 관측하는 실험의 준비 자료.

- [`sensing-sim/`](sensing-sim/) — 센싱 시뮬레이터 (필요한 장비, 테스트 환경, 테스트 시뮬레이션, 장치 연결). Three.js r128을 CDN에서 불러오는 정적 페이지다.
  - 한 부분만 보기 (노션 임베드용): `sensing-sim/?only=env` (테스트 환경), `?only=tests` (테스트 시뮬레이션), `?only=link` (장치 연결)
  - `&view=only`: 옵션·패널 없이 3D 화면만. `&test=walk`: 처음 고를 테스트(`check` `empty` `static` `pose` `walk` `occupancy` `change`). `&layout=B`: 처음 배치 후보(`F` `A`–`E`). `&zoom=1.4`: 3D 확대 배율(0.5–3).

## 해석 범위

- 배치 A–F는 설치 전 후보다. F는 공동 앵커 배치(모서리 4대 + 긴 벽 가운데 2대, 2.0/2.5 m 교대)를 그대로 쓸 때다.
- 링크 판정과 바닥 지도는 사람 상자와 공유기→수신기 직접경로의 제1 프레넬 영역(2.437 GHz)의 기하 관계다. 감지 성공률이나 실제 사각지대가 아니다.
- 신호는 직접파 + 벽·바닥·천장 1회 반사 + 몸 상자 감쇠 + 몸 중심 산란파 1개로 만든 합성 값(빈방 대비 dB)이다. 실제 ESP CSI·RSSI, 수집률, 인식 정확도가 아니다.
- 수신기의 측정값 무선 업로드와 PC 수신 프로그램은 아직 구현하지 않았다.
